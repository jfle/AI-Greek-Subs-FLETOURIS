# Requirements

- Node.js 18.17 or later, or Docker Compose v2. The Debian-family installer can install Node.js and configures systemd.
- Optional AI backup needs an English subtitle source and a compatible local model server or cloud API key.
- A reachable HTTPS address for Stremio clients that require HTTPS.

See [installation](INSTALL.md) for LAN HTTPS, Docker and legacy migration.
